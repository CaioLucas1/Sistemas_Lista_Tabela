# Sistemas de Listas e Tabelas
O planejamento do uso de listas ordenadas, não ordenadas e tabelas tem como objetivo organizar e apresentar informações de forma clara, acessível e visualmente compreensível para o usuário. As **listas ordenadas** são utilizadas quando a ordem dos itens importa, como rankings ou instruções passo a passo. Já as **listas não ordenadas** servem para destacar itens sem ordená-los, como características, categorias ou menus de navegação.

As **tabelas** são ideias para exibir dados estruturados e comparativos, como horários, preços ou estatísticas.

Durante o planejamento, é fundamental considerar a responsividade dessas estruturas, a legibilidade em diferentes dispositivos e a acessibilidade para leitores de tela. Também se define o estilo visual (espaçamento, ícones, cores) para manter a consistência com o restante do projeto.
